# Css

## Storefront uses Noir Gold theme tokens
Public storefront is scoped under `.storefront` / `[data-theme=noir-gold]` with noir, gold, ivory, muted, and line CSS tokens. Do not restyle the storefront with the default Flux zinc admin palette. Keep admin layouts on Flux; keep storefront dark charcoal + gold.
